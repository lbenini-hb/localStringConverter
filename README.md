# localStringConverter

Convertitore Base64 (encode/decode, anche URL-safe) e JWT HS256 (firma/decodifica/verifica), 100% client-side in Angular.

- Dev: `npm start` → http://localhost:4200
- Check logica: `npm run check`
- Deploy: ogni push su `main` pubblica su GitHub Pages via Actions
  (una tantum: Settings → Pages → Source: **GitHub Actions**).
